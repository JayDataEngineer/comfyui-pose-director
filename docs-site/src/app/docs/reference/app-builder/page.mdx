# App Builder Reference

Auto-generated `.app.json` files from all extension workflows.

---

## What are ComfyUI Apps?

ComfyUI's native App Builder converts workflows into simplified webapps. Instead of seeing the full node graph, users get a clean form with just the exposed inputs (prompts, seeds, sliders) and outputs (images, videos).

Apps appear in ComfyUI's **Apps sidebar tab** automatically when `.app.json` files exist in the Workflows directory.

## Generation Script

```bash
# Generate all apps
uv run python scripts/build_comfyui_apps.py

# One extension
uv run python scripts/build_comfyui_apps.py --source vnccs

# Preview without writing
uv run python scripts/build_comfyui_apps.py --dry-run

# No ComfyUI running
uv run python scripts/build_comfyui_apps.py --offline
```

## .app.json Format

A regular ComfyUI workflow JSON with extra metadata:

```json
{
  "nodes": [...],
  "links": [...],
  "extra": {
    "linearMode": true,
    "linearData": {
      "inputs": [["node_id", "widget_name"], ...],
      "outputs": ["node_id"]
    }
  }
}
```

- `inputs`: Array of `[node_id, widget_name]` pairs for exposed controls
- `outputs`: Array of node IDs for displayed outputs
- ComfyUI's frontend reads `linearData` to build the simplified UI

## Adding New Workflows

1. Place the workflow JSON in the appropriate `workflows/` directory
2. If it uses new node types, add them to `EXPOSE_RULES` and `NODE_SCHEMAS` in `scripts/build_comfyui_apps.py`
3. Re-run the script: `uv run python scripts/build_comfyui_apps.py`
4. The new app appears in ComfyUI's Apps sidebar after refresh
