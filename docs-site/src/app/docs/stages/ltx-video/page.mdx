# Stage E: LTX Video 2.3 Assembly

**Workflow**: `04_ltx_video_assembly.json`
**Extension**: Pose Director + LTXVideo

---

## What it does

Takes edited keyframe images (from Stage D) and generates a video that smoothly animates between them. Uses LTX Video 2.3 with keyframe guide injection.

### Pipeline Flow

```
UNETLoaderGGUF (ltx-2.3-22b-distilled Q4) → Model
LTXVGemmaCLIPModelLoader (Gemma 3 12B)    → CLIP + Text Encoder
VAELoader (LTX23_video_vae_bf16)           → VAE

EmptyLTXVLatentVideo (768x1024x97) → Empty 5D latent

For each keyframe:
  LTXVAddGuideAdvanced:
    - image: edited_keyframe
    - frame_idx: N (must be divisible by 8!)
    - strength: 1.0
    → Injected latent guide

KSampler (steps, CFG, seed)
  → VAEDecode → VHS_VideoCombine → MP4
```

### Key Details

- **5D latent tensor** — `EmptyLTXVLatentVideo` (NOT `EmptyLatentImage`). Shape: (batch, time, height, width, channels)
- **Full VAE required** — `LTX23_video_vae_bf16.safetensors` (1.45GB). The tiny TAEHV VAE is INCOMPATIBLE with guide injection.
- **frame_idx must be divisible by 8** — this is a hard requirement. If your keyframes don't align, the guide silently fails.
- **22B parameter model** — even at Q4 it's 16.4GB. Only fits on 24GB+ VRAM.

### Inputs
| Input | Type | Default | Description |
|-------|------|---------|-------------|
| keyframe images | IMAGE[] | — | From Stage D VNCCS edits |
| frame indices | INT[] | — | Where each keyframe appears (divisible by 8) |
| width | INT | 768 | Video width |
| height | INT | 1024 | Video height |
| length | INT | 97 | Total frames |
| seed | INT | random | Reproducibility |
| steps | INT | 20 | Sampling steps |
| cfg | FLOAT | 7 | Guidance |

### Models Used

| Model | Size | Path |
|-------|------|------|
| UNET (Q4 GGUF) | 16.4GB | `ltx-2.3-22b-distilled-1.1-UD-Q4_K_M.gguf` |
| Text Encoder | ~12GB | Gemma 3 12B via LTXVGemmaCLIPModelLoader |
| VAE (full) | 1.45GB | `LTX23_video_vae_bf16.safetensors` |
| Text projection | small | `ltx-2.3_text_projection_bf16.safetensors` |
| Connectors | small | `ltx-2.3-connectors-textproj.safetensors` |

### Failure modes

- **OOM** — 22B model is massive. Close everything else, stop llama.cpp
- **Wrong frame alignment** — guides at wrong positions = morphing video
- **Flickering** — inconsistent keyframes from Stage D. Fix the source, not this stage
- **Q4 softness** — quantization artifact. Higher quantization or post-sharpen fixes it
