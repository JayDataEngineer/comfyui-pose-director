## Stage F: LTX EditAnything Post-Processing

**Workflow**: `06_ltx_edit_anything_postprocess.json`
**Extension**: Pose Director + LTXVideo

### What it does
Uses LTX EditAnything with an IC-LoRA to fix artifacts in the generated video. Removes hallucinated text, smooths transitions, cleans backgrounds.

### Key Nodes

| Node | Purpose |
|------|---------|
| **LTXICLoRALoaderModelOnly** | Loads the EditAnything IC-LoRA onto the model |
| **LTXAddVideoICLoRAGuide** | Injects the edit guide at specific frames |

### When to use
- Hallucinated text on buildings/signs
- Background warping near character
- Minor temporal inconsistencies

### When NOT to use
- Fundamental motion problems (fix Stage D instead)
- Major anatomical errors (fix Stage A instead)
